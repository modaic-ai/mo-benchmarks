# Mo 2.0 Buying Signals artifact

`metrics.json` is the publication-safe aggregate from the complete 1,000-row
Gong Call Playbook test cohort evaluated through Modaic's production API. All
1,000 responses reported `mo-2.0` as the served model; no request failed and no
prediction was null.

The source cohort is pinned to dataset revision
`d83dd6557965c261c2de9fbf0fa04589aad528fd` and manifest SHA-256
`ba8100e7949a151b5913ceec8b63797fdd80fe2d7971a0aec0da4439ccf0f19d`.

This directory intentionally excludes licensed transcript excerpts, labels,
row-level predictions, and API credentials. The public artifact contains only
aggregate counts, metrics, and latency percentiles.

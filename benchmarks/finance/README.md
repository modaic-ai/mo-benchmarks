# Finance benchmarks

The Finance domain contains 12 fixed 200-row evaluations scored across all
nine benchmark models. Each task page describes the decision shape and reports
the complete model comparison. The separate [Finance Uplift suite](finance_uplift/README.md)
measures task-specific alignment on the same-size held-out cohorts.

- [CFPB Complaint Routing](cfpb-routing/README.md)
